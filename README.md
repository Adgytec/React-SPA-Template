# React SPA Setup

Requires these env variable setup

API endpoint and auth config
- VITE_ADGYTEC_FLOW_ENDPOINT
- VITE_CLIENT_ID

Dev server tls config
- VITE_HOST
- VITE_PORT
- VITE_DEV_TLS
- VITE_TLS_KEY
- VITE_TLS_CERT

Translations CDN config
- VITE_TRANSLATION_CDN=https://cdn.jsdelivr.net/gh/Adgytec/translations@main/src/{{lng}}/{{ns}}.json
- VITE_TRANSLATION_TYPES=https://cdn.jsdelivr.net/gh/Adgytec/translations@main/types/i18n.d.ts
